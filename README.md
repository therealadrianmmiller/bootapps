# Half Assed Software presents....BAMINA (Boot Apps Manager Is Not Autostarts)

## What it is:

Its a simple no frills GUI to disabled (or enable) apps that run at boot, WITH import/export

## What is does:

- Lists all 3rd party apps that start at boot
- Allows to enable/disable them
- Allows you to export the list and the state of each app
- Allow you to import and replicate the state of matched apps (if an app was set to disabled in export, its immediately disabled on import)

While i loved AutoStarts for years, it never included and import/export function, and i hate having to manually replicate my settings after
a ROM flash/factory reset

## Requirements:

- Root
- Root granted to the app manually in your root manager

Without root, the app will revert to taking you to an apps info page to disable the entire app, a sure sign you missed granting root :)
